# Type experiments

## Live demo

https://type-experiments-cyan.vercel.app

The root URL opens Shape Type. The other two toys stay in the repo and are reachable by direct link.

- [shape-type](https://type-experiments-cyan.vercel.app/shape-type)
- [ornament-type](https://type-experiments-cyan.vercel.app/ornament-type)
- [origami-type](https://type-experiments-cyan.vercel.app/origami-type)
- [all three on one page](https://type-experiments-cyan.vercel.app/landing)

Three interactive typing toys. Each folder is one self-contained `index.html`, no build step.

- `shape-type`: an original geometric alphabet built from simple shapes.
- `ornament-type`: letters grow swashes, curls and tails that behave like ropes.
- `origami-type`: letters made of paper triangles that unfold like folded paper.

## Credits

Inspired by [Type Garden](https://type-garden.vercel.app/) by Akshat Agarwal, where letterforms grow as you type. The typing interaction here follows that idea: type to build, space to finish a word, backspace to undo, enter to clear.
